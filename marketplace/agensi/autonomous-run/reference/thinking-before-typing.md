# thinking-before-typing

Restate the user outcome, scope, non-goals, and acceptance criteria first. Code comes after the decision is visible.

**When:** Starting a feature, refactor, or any material product change.

**Why:** Generation speed makes unexamined ideas look finished. Writing exposes disagreement while change is cheap.

**Do not:** Open with a scaffold or rewrite when the outcome is still conversational.

Cite `reference/thinking-before-typing.md` when it changed a decision. Keep the citation specific.
