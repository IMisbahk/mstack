# evidence-over-optimism

Record the budget, measure the bottleneck, then make the smallest change that moves the number.

**When:** Performance work, scaling proposals, or 'we might need' infrastructure.

**Why:** Speculative caches and services add operational cost before the product earns them.

**Do not:** Add distributed complexity to look production-ready.

Cite `reference/evidence-over-optimism.md` when it changed a decision. Keep the citation specific.
