# encode-lessons-in-structure

If you write the same instruction twice, encode it where the next agent or human will hit it: lint, test, schema, ADR, or task recipe.

**When:** A mistake recurs, a review comment repeats, or a playbook step keeps being skipped.

**Why:** Prose fades; structure keeps teaching after the chat ends.

**Do not:** Add more reminder text when a mechanical guard would catch the same failure.

Cite `reference/encode-lessons-in-structure.md` when it changed a decision. Keep the citation specific.
